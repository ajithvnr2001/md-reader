# Welcome to MD Reader

This is a **sample Markdown file** stored in Cloudflare R2 and served
through a Cloudflare Worker.

## What is this?

MD Reader is a mobile-friendly Markdown viewer designed for students who
want to read notes comfortably, day or night. Every file you upload to
your R2 bucket automatically shows up in the sidebar.

## Features

- Reads `.md` files directly from **Cloudflare R2** (no database needed)
- Day and night reading themes with adjustable font size
- AI-powered study tools using **Cloudflare Workers AI**:
  - Summarize an entire document
  - Explain a selected passage in simple terms
  - Auto-generate a 5-question quiz

## How it works

1. You upload Markdown notes to an R2 bucket (`wrangler r2 object put ...`)
2. The Worker lists and streams those files to the browser
3. The browser renders Markdown client-side with `marked.js`
4. When you tap an AI button, the Worker calls `env.AI.run()` and returns
   a response generated by a Llama 3.1 model running on Cloudflare's edge

> Tip: Try selecting a paragraph and tapping **Explain selection** to see
> Workers AI in action.

## Code example

```javascript
const object = await env.MD_BUCKET.get("intro.md");
const text = await object.text();
```
